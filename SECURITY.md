# Security Policy

## Supported Versions

Only the latest published version receives fixes.

## Reporting a Vulnerability

Report it through GitHub's private vulnerability reporting:
**[Open a private vulnerability report](https://github.com/anilcancakir/magic_encryption/security/advisories/new)**

The report stays confidential until a fix is ready. Include the affected version, the platform, and the steps to reproduce.

## Scope

This policy covers the `magic_encryption` package: the `Crypt` facade, the encrypter and the `key:generate` command. Issues in `pointycastle`, `dowel` and the Flutter SDK belong to their maintainers.
